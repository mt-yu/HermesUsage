## 先动手

> 入门课的原则：**先看到结果，再理解原理**。这一段必须 3 分钟内跑出可见的东西。

```bash
# 一条可以直接复制粘贴的命令
hermes chat -q "你好，用一句话说说你能做什么"
```

你应该看到（预期输出长这样）：

```
<真实输出片段，粘贴你实际跑出来的东西，不要编>
```

## 原理

用「为什么」解释刚才发生了什么。可以配一张 ASCII 图或表格。

**判据**：如果读者只读这一节而不动手，也应该能向别人解释这个机制。
