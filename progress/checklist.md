# 学习进度清单

> 打勾标准只有一个：**能不看笔记做出来**。
> 命令看进度：`python scripts/progress.py` ｜ 下一课：`python scripts/progress.py next`
> 每完成一课，按 [CONTRIBUTING.md](../CONTRIBUTING.md) 归档一次：
> `python scripts/journal.py commit --kind session --title "完成 L01" --scope L01`

---

## 阶段 0 · 认识 Hermes

- [ ] 我能用一句话说清 Hermes 与「网页版聊天机器人」的区别
- [ ] 我说得出它自我改进的两个机制，以及各自存在磁盘的哪里
- [ ] 我能列出同一个内核的 5 种外壳，并说明为什么学内核比学界面划算
- [ ] 我装好了 Hermes，并跑通了一次「它真的用了工具」的对话
- [ ] 我能复述 agent loop 的一轮步骤
- [ ] 我知道 SOUL.md / USER.md / MEMORY.md / `.hermes.md` / config.yaml 各管一件事

**出口检验**：合上文档，向一个朋友解释「Hermes 是怎么工作的」，讲满 2 分钟不卡壳。

---

## 阶段 1 · 会用（核心五件事）

- [ ] 我能用 `hermes config get model` 查出当前主模型，并解释 `provider` / `base_url` 的含义
- [ ] 我说得出「中途换模型为什么贵」，并知道该在什么时候换
- [ ] 我能用 `hermes tools` 开关工具集，用 `--toolsets` 限制单次运行
- [ ] 我知道终端后端有哪几种，并说清什么情况下必须换掉 `local`
- [ ] 我会用 `/status` 和 `/context` 自查会话与上下文
- [ ] 我理解「冻结快照」，知道为什么改完规则要开新会话
- [ ] 我给一个真实项目写了 `.hermes.md`，并用 `/context` 验证它被加载
- [ ] 我写了一个自己的技能，并用 `/技能名` 成功调用
- [ ] 我跑过一次 `/refine`，看它把经验沉淀成技能或记忆

**出口检验**：给一个陌生项目配好 `.hermes.md` + 一个技能，让它跨会话记住一条约定。

---

## 阶段 2 · 日常威力

- [ ] 我能把模糊需求改写成「有可验证判据」的任务
- [ ] 我踩过至少一次「上下文被啰嗦文本撑爆」，并学会改用文件路径
- [ ] 我用 `delegate_task` 跑过一次并行子任务，并知道什么不该外包
- [ ] 我建过一个 cron 任务，并验证它真的在预定时间跑了
- [ ] 我知道 `/rollback` / `/diff` 怎么用，并亲手回滚过一次改坏的文件
- [ ] 我从配方库里抄了至少 3 个流程用在自己身上

**出口检验**：让它独立完成一件需要 3 步以上、且你能验收的活。

---

## 阶段 3 · 自动化与多代理

- [ ] 我写过一个 hook（或看懂了一个 hook 的执行时机）
- [ ] 我配过一个 webhook，让外部事件触发了 agent
- [ ] 我用 kanban（或 bot mode）协调过两个以上的 agent/任务
- [ ] 我把 Hermes 接上了一个消息平台，并在手机上用上了它
- [ ] 我拼出过一条「无人值守」的链路（cron + skill + 投递）

**出口检验**：连续 3 天，有一件事是 Hermes 在你不干预的情况下完成的。

---

## 阶段 4 · 扩展与改造

- [ ] 我写过一个带 `references/` 的完整技能
- [ ] 我写过一个插件（工具或钩子），并装上生效
- [ ] 我改过外观（皮肤 / 桌面插件 / TUI 部件）之一
- [ ] 我通过 MCP 接上了一个外部工具服务器，并做了工具筛选
- [ ] 我用 Python 或 ACP/API 把 Hermes 嵌进过自己的程序

**出口检验**：Hermes 缺的能力，你能自己加上，而不是等官方更新。

---

## 阶段 5 · 运维与安全

- [ ] 我说得出默认的审批机制在什么情况下会拦住命令
- [ ] 我把密钥放在了对的位置，并检查过没有密钥写进 `config.yaml`
- [ ] 我能解释 prompt caching 的收益，以及哪三种操作会毁掉它
- [ ] 我按排障手册诊断过一次「它变笨了」
- [ ] 我升级过一次，并且知道出事怎么退回去

**出口检验**：敢把它放在你每天在用的机器上，并且出问题时有章法。

---

## 毕业项目

- [ ] 我选定了一个自己真实在做的流程，并写下了验收标准
- [ ] 我把它做成了「技能 + 自动触发」的组合
- [ ] 我能证明它确实在跑（有日志 / 有投递 / 有产物）
- [ ] 我用 git journal 记录了整个过程，能倒着走回去
- [ ] 我写下了一条给下一位学习者的经验

**出口检验**：这个项目在你不管它的时候，依然在产生价值。

---

## 每周 5 分钟的维护（很值）

- [ ] 让它把 `MEMORY.md` / `USER.md` 逐条读给你，删掉错的、合并重复的
- [ ] `hermes skills list` 看一眼技能数量，把不用的关掉
- [ ] `python scripts/journal.py log` 回顾这周做了什么
- [ ] `python scripts/sync_sources.py --check` 看官方文档有没有改版（本仓库的出处是否需要更新）
