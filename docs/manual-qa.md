# 发布前手工验收清单（17 条）

自动化能覆盖的（内容门禁、单元测试、站点构建与链接自检）交给 `python scripts/check.py`，
**这份清单只列自动化盖不住的事**：真实浏览器里的交互与渲染。每次发布前跑一遍。

```bash
python scripts/serve.py --open     # 本地起站；线上版同理（把 URL 换成 Pages 地址）
```

| # | 操作 | 应该看到 |
|---|---|---|
| 1 | 打开首页 | 三栏布局；侧栏按阶段列出 32 课；进度卡显示 `0 / 32`、进度条为空 |
| 2 | 点某课左侧的 ○ 圆圈 | 该课标题变灰加删除线；顶栏胶囊 +1；进度条有宽度；**刷新后保持** |
| 3 | 课程页点一个练习方框 | 方框变实心；刷新后仍勾着；再点一次取消，`localStorage["hermes-usage:exercises:v1"]` 里该题键消失 |
| 4 | 分别勾练习与勾课程 | 两个存储键各自变化、互不影响（`progress` / `exercises`） |
| 5 | `Ctrl+K` 或 `/` 开搜索 | 输入 `cron` 首条是 L23；输入 `项目技能` 出现 L15；`↑↓` `Tab` `Shift+Tab` 在结果间环绕且**焦点不逸出**；`Enter` 打开；`Esc` 关闭且焦点回到搜索按钮 |
| 6 | 悬停正文里的 `src:…` 徽标 | tooltip 显示 `hermes v…` 与 sha256 前缀；点击新标签打开官方文档 |
| 7 | 点 `[[L13]]` 变成的链接 | 跳到该课页面，不是 404 |
| 8 | 课程页右侧目录 | 8 个小节齐全；滚动时高亮跟随 |
| 9 | 课程页按 `→` / `←` | 去下一课 / 回上一课；第一课按 `←` 不动，L90 按 `→` 不动 |
| 10 | 打开 `/map.html` | 32 行课程；地图上点圆圈能打勾且刷新后保持；侧栏有「学习地图」入口 |
| 11 | 点顶栏 `◐` 切主题 | 亮/暗都正常；刷新后保持选择 |
| 12 | 把窗口拖窄到 900px 以下 | 侧栏收起；左上汉堡按钮能拉出抽屉；点正文外部收起 |
| 13 | 走完以上操作后看控制台 | **零未捕获异常**（`addEventListener('error')` 无触发） |
| 14 | 首页或地图页点「导出学习报告」 | 下载 `hermes-usage-report.md`；里面汇总行的课数/练习数与页面一致，按阶段分表齐全 |
| 15 | 打开 `/offline.html`（或下载后双击） | 单文件可读、样式生效；顶部目录能跳到对应课；断网也不影响阅读 |
| 16 | 打开仓库首页首屏的「学习路线图」 | 是一张深色底的图（不是代码块）：中文正常、芯片文字不溢出边框、7 个阶段都带「N/N 课就绪」；失败时先跑 `python scripts/build_roadmap_svg.py --check`（应为 0） |
| 17 | 改任意一课的标题后跑 `python scripts/check.py` | 报「路线图 SVG 同步」失败并打印差异；跑 `python scripts/build_roadmap_svg.py` 后重回 6 项全绿 |

> 第 13 条可以脚本化：注入
> `addEventListener('error',e=>__errs.push(e.message))` 与 `unhandledrejection` 监听后再做上面 1-12 条。
